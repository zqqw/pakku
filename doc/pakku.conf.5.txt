pakku.conf(5)
=============

Name
----
pakku.conf - pakku configuration file

Synopsis
--------
\{sysconfdir\}/pakku.conf

Description
-----------
This configuration file uses a similar format to pacman.conf. The file is
divided into sections. Only options section is used. A '#' begins a comment
when it starts a line or follows whitespace, so a comment may also terminate
an option's line. Flag options accept an optional value (`true`, `yes`, `1`,
`false`, `no`, `0`); a flag without a value is enabled. Values of options that
list alternatives must be spelled exactly as shown. Unknown options, unknown
values and unparsable flag values are reported as errors.

Options
-------
*UserCacheDir =* path/to/user/cache/dir::
	Set the cache directory in which pakku will cache repositories.
	The default value is +$\{HOME\}/.cache/pakku+.

*TmpDir =* path/to/tmp/dir::
	Set the temporary directory in which pakku will perform all
	building operations. The default value is +/tmp/pakku-$\{USER\}+.

*PackageOutputDir =* path/to/package/output/dir::
	Built package archives (\fB*.pkg.tar*\fP) are written to this
	directory, separating package output from the transient build
	workspace in +TmpDir+. Supports the same variable expansion as
	+TmpDir+ (+\fB${USER}\fP+, +\fB${HOME}\fP+, +\fB${UID}\fP+,
	+\fB$$\fP+). Defaults to +TmpDir+ when unset or empty.

*AurRepo =* name::
	Set the fake AUR repository name. This name should not conflict with
	names of declared repositories. The default value is +aur+.

*AurComments*::
	Download and display comments for AUR packages.

*CheckDevel*::
	Check development packages for upstream changes during AUR upgrades. A
	development package (one named +-git+, +-svn+, +-hg+ or +-bzr+, or already
	recorded) is offered for rebuild when its AUR info time changed after the
	installed copy was built, and, for a recorded package, when a git ref target
	changed. Pakku records the resolved refs in +devel.json+ under the user cache
	directory after a successful build of a PKGBUILD that defines a +pkgver()+
	function. A package with no state entry yet is decided by its AUR info time
	alone, and saves state the next time it is built with this check enabled.
	Upstream changes are only detected for git sources, and only when a recorded
	ref target changes.

*IgnoreDevel*::
	Package names or glob patterns whose devel-specific offers are ignored.
	An ignored package is still considered by ordinary version comparison.
	Names are separated by whitespace or commas; `*` and `?` are wildcards.

*IgnoreDevelSource*::
	Git source URL glob patterns that are excluded from ref checks and from
	saved devel state. Useful for unversioned secondary sources that would
	otherwise make a package look stale. Separate patterns by whitespace or
	commas.

*DevelSuffixes*::
	Suffixes that mark a package as development for AUR info-time checks and
	for suppressing misleading version warnings. Defaults to +git+, +svn+,
	+hg+, +bzr+, +cvs+, +darcs+, +always+, +fossil+, +nightly+ and
	+insiders-bin+; +always+ also matches the +-always-+ infix. Separate
	entries by whitespace or commas, with or without a leading dash. Only
	git sources are followed for upstream ref changes; other suffixes affect
	classification, not tracking.

*CheckIgnored*::
	Check ignored packages for updates in AUR. Pakku will be able to warn
	about ignored package upgrade.

*IgnoreArch*::
	Ignore a missing or incomplete arch field in the build script. Pakku
	will pass '\--ignorearch' option to linkman:makepkg[8].

*PrintAurNotFound*::
	Print warnings during upgrade operation when foreign packages were not
	found in AUR.

*PrintLocalIsNewer*::
	Print warnings during upgrade operation when local packages are newer
	than those found in remote repositories.

*SudoExec*::
	Automatically exec the program from root via the configured privilege
	helper if it is necessary, allowing one password prompt.

*ViewNoDefault*::
	When building from AUR, pakku will ask whether you want to view the
	content of PKGBUILD and other files. Pressing enter key will give the
	positive answer unless this option is specified.

*KeepBuildDirOnFailure*::
	When enabled, pakku preserves the build workspace (cloned repositories
	and build directories) when a build fails. By default the workspace is
	removed on failure.

*KeepBuiltPackagesOnFailure*::
	When enabled, pakku preserves built package archives where they were
	written (+PackageOutputDir+ or the staging directory) when a build fails.
	By default archives are removed on build failure.

*PreserveBuilt =* Internal | User | Pkgdest | Disabled::
	Copies the archives selected for installation to a directory that outlives
	the run, so a later install reuses them. Internal copies to pacman's cache
	directory. Pakku holds a single cache path, so a repeated +CacheDir+
	directive leaves only the last entry in effect. User copies to
	+${UserCacheDir}/packages+. Pkgdest copies to the effective +PKGDEST+, where
	an exported +PKGDEST+ wins over linkman:makepkg.conf[5]. An empty result is
	a no-copy mode, not an error. Disabled is the default. The copy happens
	after the install is confirmed and before pacman runs, so a cancelled
	install leaves nothing behind, and the destination is also scanned for
	reuse. +PAKKU_PRESERVE_DIR+ replaces the destination for one invocation, see
	*ENVIRONMENT* in linkman:pakku[8].

*CleanupAfterInstall =* Full | Worktree | None::
	Controls cleanup of build artifacts and workspace after a successful
	install. Full (the default) removes both temporary build directories
	and built package archives. Worktree removes build directories but
	preserves package archives selected for installation in the output
	directory for reuse on subsequent runs. None preserves the workspace and
	selected package archives. Unselected split-package sibling archives are
	removed in Worktree and None modes.

*PreBuildCommand =* command::
	This command will be executed in package directory before building,
	allowing you to modify PKGBUILD or perform other necessary actions.

*PreferredSudoCommand =* command::
	This is the command that will be used to escalate privileges. If the option is
	not set or the command is not found on the system, pakku will try to guess the
	command between sudo, doas and su.

Package and build policies
--------------------------
Pakku builds in a temporary workspace and removes the work after a successful
install by default. The options below retain parts of it.

Build output::
	+PackageOutputDir+ moves makepkg's +PKGDEST+ out of the temporary
	workspace. The default is +TmpDir+. Pakku scans the directory for reuse
	before building. An exported +PKGDEST+ overrides the value pakku writes into
	the build configuration.

Cleanup::
	+CleanupAfterInstall = Full+ (the default) removes the workspace and local
	archives. +Worktree+ retains installed archives in the output directory.
	+None+ retains the workspace as well. The last two retain only archives
	selected for installation, and remove unselected split-package siblings.

Failure::
	+KeepBuildDirOnFailure+ and +KeepBuiltPackagesOnFailure+ retain the
	workspace or the archives already written when a build fails.
	+CleanupAfterInstall+ applies to successful installs only.

Copy destination::
	+PreserveBuilt+ copies the archives selected for installation to a
	directory that outlives the run. The copy is made after the install is
	confirmed and before pacman runs. Archives in that directory are exempt
	from cleanup and are scanned for reuse.

Environment override::
	+PAKKU_PRESERVE_DIR+ replaces the copy destination for one invocation. The
	path must be absolute, must exist, and must lie outside the build output.
	When it displaces a mode other than +Disabled+, pakku reports the
	override.

Reuse::
	Reuse requires every expected archive for the base to be present and
	non-empty in one directory, checked in the build output first and in the
	copy destination second. Matching is by file name. +CacheDir+ is unsuitable
	as a build store because +pacman -Sc+ and downloads change it
	independently.
